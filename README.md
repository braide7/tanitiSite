# Taniti Tourism Site

A vibrant, fictional tourism website for the tropical island of Taniti, crafted with HTML, CSS, and JavaScript. Designed with a mobile-first approach, it delivers a seamless and stunning experience across both mobile and desktop devices.

The website is live at https://taniti-site-nu.vercel.app/
